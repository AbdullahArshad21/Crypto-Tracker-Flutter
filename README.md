# Crypto Tracker 📈

A cross-platform cryptocurrency tracking app built with Flutter — live prices, charts, news, and favorites, with Firebase-backed authentication.

## Features

- **Live tracking** for 100+ cryptocurrencies with price charts
- **Live crypto news** feed from an external news source
- **Favorites** section to bookmark coins for quick access
- **Light & dark theme** support
- **Email/password authentication** via Firebase Auth, with user data in Cloud Firestore
- Cross-platform: Android, iOS, Web, and Windows

## Tech stack

- **Framework**: Flutter (Dart)
- **Auth & database**: Firebase Authentication, Cloud Firestore
- **Market data**: [CoinGecko API](https://www.coingecko.com/en/api)
- **News data**: NewsAPI / Newsdata.dev
- **Charts**: Syncfusion Flutter Charts
- **State management**: Provider
- **Other packages**: `fluttertoast`, `shared_preferences`, `shimmer`, `page_transition`, `animated_splash_screen`, `readmore`

## Getting started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (Dart SDK `>=2.16.1 <3.0.0`)
- A Firebase project (Authentication + Firestore enabled)
- API keys for your market data and news providers

### Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/AbdullahArshad21/Crypto-Tracker-Flutter.git
   cd Crypto-Tracker-Flutter
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Configure Firebase**
   Connect your own Firebase project using the [FlutterFire CLI](https://firebase.google.com/docs/flutter/setup):
   ```bash
   flutterfire configure
   ```
   This regenerates `lib/firebase_options.dart` for your project. See `FIREBASE_CONNECTION_GUIDE.md` in this repo for more background on how Firebase is wired up.

4. **Add your news API key**
   In `lib/pages/news.dart`, replace the `YOUR_API_KEY` placeholder in the news API request URL with your own key.

5. **Run the app**
   ```bash
   flutter run
   ```
   Select a connected device/emulator, or pass a platform flag, e.g. `flutter run -d chrome` for web or `flutter run -d windows` for desktop.

### Build

```bash
flutter build apk        # Android
flutter build ios        # iOS
flutter build web        # Web
flutter build windows    # Windows
```

## Security note

This repo currently includes committed documentation with live Firebase project identifiers and a test-account password (`FIREBASE_AUTHENTICATION_STATUS.md`, `FIREBASE_CONNECTION_GUIDE.md`). Before making this repo public or shipping it, rotate any exposed credentials, move Firebase config to environment-specific setup (not committed docs), and remove hardcoded API key placeholders from source in favor of a `.env`/secrets approach (e.g. `flutter_dotenv`).
